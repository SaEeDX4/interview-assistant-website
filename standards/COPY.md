# COPY.md — Interview Assistant voice and copy standard

The one-page style sheet for every word on the website. Distilled from
the Apple Style Guide / HIG, the Google developer documentation style
guide, and the Microsoft Writing Style Guide (research:
website-copy-craft-research, 2026-11-18). When this file and a draft
disagree, the draft loses.

## Voice

Calm, plain, on your side. We sound like a knowledgeable friend who
has sat through a hundred interviews — never like a salesperson,
never like a lawyer, never like a hype account.

## Rules

1. Sentence case everywhere, including headings. No Title Case.
2. Second person ("you"), active voice, present tense.
3. Contractions are normal ("you'll", "it's"). Sound like speech:
   read every line aloud before it ships.
4. Sentences average 15–20 words; none over 25 without a reason.
   Paragraphs are 1–3 sentences. Reading level: grade 6–8.
5. Verb-first buttons and links that say what happens next
   ("See how it works", "Try the demo") — never "Click here",
   never "Submit".
6. Numbers as numerals. One fact per sentence.
7. No jargon without a plain gloss in the same breath.
8. No exclamation marks in product UI copy.
9. Ban list: superlatives without proof ("best", "#1"), guaranteed
   outcomes ("land any job", "pass every interview"), "undetectable",
   fake urgency ("limited time", countdowns), and any testimonial,
   rating, user count, or employer logo we cannot prove.
10. Every claim carries its limit next to it. The demo is labelled
    simulated; generated answers are labelled "live", never "AI".

## Section rhythm (the benchmark pattern)

Eyebrow (small label) → benefit headline of 3–8 words → one or two
sentences, 15–40 words total → proof, or the honest limit. If a
section needs a third sentence, it is usually two sections.

## Feature ladder

Feature (what it does) → benefit (what that means for the reader) →
proof or limit (how we know / where it stops). Never a spec alone.

## Pricing (pre-launch)

No number is published until the owner locks the price. State the
unknowns plainly ("Pricing is not final yet"), say what the trial
includes, and give one honest next action.

## Microcopy

- Errors: what went wrong + what to do now, in plain words.
- Empty states: what is missing + the next action.
- Honesty notes live under the button they qualify (Raycast pattern),
  not in a footnote three sections later.

## Editing gate (every rewrite)

Intent line per page → structural cut → sentence pass against this
file → read aloud → claims lint against rule 9/10 → readability
check (rule 4) → headline-only cold read. The battery must stay
green; copy that breaks a test updates the test only when the new
words are the deliberate replacement.
